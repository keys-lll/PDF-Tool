PDF 併頁器 1.1.0 — Windows 可攜版
=====================================

系統需求
--------
- Windows 10 或 Windows 11，64 位元
- 不需要安裝 Python，也不需要管理員權限

啟動
----
1. 將整個 PDF-Page-Merger 資料夾解壓縮到可寫入的位置。
2. 執行 PDF-Page-Merger.exe。
3. 請保留同資料夾中的 _internal 目錄，程式需要它才能啟動。

這是免安裝可攜版。若要建立桌面捷徑，可以對 PDF-Page-Merger.exe
按右鍵，選擇「傳送到」→「桌面（建立捷徑）」。

Windows SmartScreen
-------------------
這個版本沒有數位簽章，第一次啟動時 Windows 可能顯示 SmartScreen
警告。確認檔案來自本專案的 GitHub Release 後，可選擇「更多資訊」
→「仍要執行」。若不想略過警告，請自行從原始碼建置。

功能
----
- 一次加入多份 PDF，支援拖放。
- 全頁縮圖畫廊，可直接拖曳即時換位。
- 加密 PDF 逐檔輸入密碼，可重試或稍後解鎖。
- 可多選頁面刪除，也可使用上移／下移按鈕。
- 合併前提醒尚未解鎖的 PDF。
- 合併結果以暫存檔原子替換，避免留下半成品。
- 縮圖使用內建的 PDFium，不需要額外安裝 poppler。

快速鍵
------
Ctrl+O       新增 PDF
Ctrl+S       合併並儲存
Alt+Up       上移目前頁面
Alt+Down     下移目前頁面
Delete       移除選取頁面
Ctrl+Q       結束程式

隱私與暫存檔
------------
- PDF 密碼只存在記憶體，不會寫入設定檔或日誌。
- 解密後的工作副本與縮圖位於 %TEMP%\pdf-page-merger-*。
- 正常關閉程式後會刪除暫存資料夾；強制終止時可能留待系統清理。
- 來源 PDF 不會被修改，輸出是新的未加密 PDF。

已知限制
--------
- 合併結果不保證保留書籤、表單欄位、附件或數位簽章。
- 尚未提供 Windows 安裝程式；目前是免安裝 zip 可攜版。
- 未簽章執行檔可能觸發防毒軟體或 SmartScreen 警告。
